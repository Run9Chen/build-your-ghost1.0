# Codex 后续开发 Prompt

请基于这个 Next.js 项目继续开发。

项目是一个中文互联网人格测试 + AI 数字人格产品原型：

- `/quiz` 是“你是什么鬼？”测试，用来引流。
- `/` 和 `/ghost` 是 Build Your Ghost / 赛博永生器主产品入口。

请保持以下风格：

- 黑色背景
- 白色呼吸光核
- 漂浮记忆纸片
- 中文网感文案
- 极简、孤独、赛博、带一点地府幽默

下一步优先开发：

1. 给 `/quiz` 增加结果分享卡片。
2. 允许用户复制结果文案。
3. 在结果页加入“保存我的今日鬼格”。
4. 把测试结果作为 Build Your Ghost 的初始 profile。
5. 给 `/ghost` 加一个输入框：每天一句话。
6. 把每日一句话保存到 localStorage。
7. 根据 localStorage 生成漂浮记忆纸片。

注意：不要把页面做成普通 MBTI 网站。这个项目的核心气质是“赛博地府 + 数字幽灵 + AI 日记”。
